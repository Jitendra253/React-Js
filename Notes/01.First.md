# CDN:
    A CDN (Content Delivery Network) is a distributed network of servers that delivers static assets such as JavaScript, CSS, images, and videos from a location closer to the user, improving loading performance and reducing latency.
# Important Packages:
    1. Bundler (webpack,Parcel,vite)
        - A bundler is a tool that takes your project's multiple files and dependencies and combines/processes them into optimized files that the browser can load efficiently.
            - Parcel: Parcel is a zero-configuration bundler that automatically handles many build configurations and frontend assets.
    Ther are two types dependencies 1.dev dependencies and 2. normal dependenites (can be used in production also) -D tells npm to install in dev dependencies. 

# npm Version Symbols
    - `^` **Caret** → Allows **minor + patch** updates.

        ```json
        "react": "^18.2.0"
        ```

        Allows `18.x.x`, but not `19.x.x`.

    - `~` **Tilde** → Allows **patch** updates only.

        ```json
        "react": "~18.2.0"
        ```

        Allows `18.2.x`, but not `18.3.x`.

    - **Exact version** → No automatic version range.

        ```json
        "react": "18.2.0"
        ```
# package.json vs package-lock.json

- **package.json** → Contains project details, scripts, and dependencies with version ranges.
- **package-lock.json** → Contains the exact versions of installed packages and dependencies.

### Remember

package.json → What the project needs  
package-lock.json → Exact versions installed
